# Полная русская локализация WORLD OF HORROR

## Установка

Нужны [Python](https://www.python.org/downloads/) 3.11 или новее и консольная версия [UndertaleModTool](https://github.com/UnderminersTeam/UndertaleModTool) (`UndertaleModCli`).

Укажите путь к `UndertaleModCli` и запустите установку из корня репозитория:

```sh
# Linux
UTMT_CLI=/путь/к/UndertaleModCli python3 -I woh.py install
```

```powershell
# Windows
$env:UTMT_CLI = "C:\путь\к\UndertaleModCli.exe"
python -I woh.py install
```

Скрипт соберёт файлы локализации и новый `data.win` с переведёнными картинками и шрифтами, а затем скопирует их в папку игры.

Игра ищется в стандартной папке Steam:

- Windows: `C:\Program Files (x86)\Steam\steamapps\common\WOH`
- Linux: `~/.local/share/Steam/steamapps/common/WOH`

Если игра установлена в другую библиотеку Steam, укажите её папку: `woh.py --game "ПАПКА" install`.

### Как откатить или установить заново

Выберите в Steam «Проверить целостность файлов игры»: оригинальные файлы вернутся на место.

Этот же шаг нужен перед повторной сборкой. Скрипт не принимает собственные файлы за оригинальные и откажется работать, пока в папке игры лежит установленный перевод.

### Текст, зашитый в исполняемый файл

Часть текста находится не в файлах локализации, а в самом `worldofhorror.exe`. Команда `woh.py install --exe` дополнительно устанавливает пропатченный exe.

Эта возможность не проверялась в самой игре, поэтому по умолчанию выключена. Для неё также нужны [Ghidra](https://ghidra-sre.org/) (путь к `analyzeHeadless` в переменной `GHIDRA_HEADLESS`) и `clang`. Первый анализ игры занимает десятки минут, но его результат сохраняется.

## Команды

Все команды запускаются как `python -I woh.py [--game ПАПКА] <команда>`. Каждая сама собирает всё, что ей нужно и чего ещё нет.

| Команда             | Что делает                                                               |
| ------------------- | ------------------------------------------------------------------------ |
| `install [--exe]`   | Собирает перевод и копирует его в папку игры                             |
| `all`               | Собирает всё в папку `output/`, не трогая игру                           |
| `text`              | Собирает файлы локализации                                               |
| `sprites`           | Собирает `data.win` с переведёнными картинками и шрифтами                |
| `exe [--literal]`   | Собирает пропатченный `worldofhorror.exe`                                |
| `sync`              | Обновляет файлы перевода после обновления игры, сохраняя готовый перевод |
| `report`            | Показывает, какие спрайты и кадры игра действительно использует          |
| `extract`           | Извлекает все кадры в `img/source/`                                      |
| `ocr`               | Распознаёт текст на извлечённых кадрах                                   |
| `save [ФАЙЛ] ВЫХОД` | Создаёт сохранение со всем открытым, для проверки перевода               |
| `check`             | Проверяет размеры картинок и патч                                        |
| `list`              | Показывает все этапы сборки                                              |

Пути к инструментам задаются переменными окружения: `UTMT_CLI`, `GHIDRA_HEADLESS`, `WOH_GHIDRA_JAVA` (`JAVA_HOME` для Ghidra). Для `ocr` и `check` нужен [uv](https://docs.astral.sh/uv/).

## Строение репозитория

| Путь                                             | Содержимое                                                                                                          |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------- |
| `woh.py`                                         | Точка входа: все команды запускаются через него                                                                     |
| `translation/language/engLanguage/`              | Перевод игрового текста                                                                                             |
| `translation/exe_strings.txt`                    | Перевод текста из `worldofhorror.exe`                                                                               |
| `translation/todo.txt`, `translation/unused.txt` | Какие картинки ещё нужно перевести и какие переведённые игра не использует                                          |
| `translation/notes.md`                           | Заметки о переводе                                                                                                  |
| `img/translation/`                               | Переведённые картинки, `.png` и исходники `.psd`. Их можно открыть в любом подходящем приложении (Photoshop, Krita) |
| `font/`                                          | Отредактированные листы шрифтов `silver_big`, `silver_small` и `silver_vsmall`                                      |
| `pipeline/reverse/`                              | Шаг 1: анализ установленной версии игры                                                                             |
| `pipeline/generate/`                             | Шаг 2: создание нужных для сборки файлов                                                                            |
| `pipeline/act/`                                  | Шаг 3: сборка перевода, сохранений и картинок                                                                       |
| `pipeline/check/`                                | Проверки                                                                                                            |
| `pipeline/README.md`                             | Устройство скриптов и заметки по реверс-инжинирингу игры (на английском)                                            |

В репозитории хранятся только скрипты и то, что сделано вручную. Всё остальное создаётся заново и не отслеживается:

- `build/`: результаты анализа, отдельно для каждой версии игры
- `output/`: собранный перевод
- `img/source/`: извлечённые из игры кадры

## Как устроены файлы перевода

Файлы в `translation/` состоят из строк вида `английский текст|русский текст`:

- Пустая часть после `|` означает, что строка ещё не переведена.
- Символ `#` обозначает перенос строки.
- `<<#>>` является разметкой игры, а не разделителем, поэтому его нужно сохранять как есть.
- Английскую часть менять нельзя: по ней перевод сопоставляется со строками игры.
- В `exe_strings.txt` спецсимволы записываются как `\\`, `\r`, `\n` и `\t`.

Новая картинка должна называться так же, как кадр игры (`<спрайт>_<кадр>.png`), и иметь тот же размер. Лист шрифта тоже должен совпадать по размеру с оригиналом.

## Лицензия

Репозиторий лицензирован под [WTFPL](http://www.wtfpl.net/).
Это означает, что вы можете безнаказанно использовать и модифицировать перевод в каком угодно виде. Вы можете делать всё, что захотите.
